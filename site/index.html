Sobre o projeto

Uma forma simples de acompanhar a rotina de cuidado.

O projeto foi desenvolvido para facilitar o registro e a consulta de informações relacionadas à pessoa idosa. A proposta é apoiar familiares e cuidadores no dia a dia, com uma experiência direta e fácil de entender.

O aplicativo foi desenvolvido em Flutter e conta com uma API em Node.js.

O que o Ello reúne
01

Informações da rotina

Registros organizados para facilitar o acompanhamento cotidiano.

02

Dados de cuidado

Acompanhamento de glicemia, refeições, insumos e outras informações importantes.

03

Apoio para cuidadores

Uma visão mais clara para quem participa da rede de cuidado da pessoa idosa.

Nosso objetivo

Tecnologia como apoio para um cuidado mais tranquilo.

O Ello busca reduzir a dificuldade de organizar informações e tornar a rotina de quem cuida mais prática.
